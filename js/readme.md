
Paws & Claws Animal Rescue Website

Project Overview

Paws & Claws Animal Rescue is a responsive website designed to help abandoned and rescued animals find loving homes. The website provides information about adoption services, volunteering opportunities, sponsorship programmes, and contact details.

⸻

Features

Responsive Design

* Mobile-friendly layout
* Tablet-friendly layout
* Desktop-friendly layout
* CSS Media Queries used for responsiveness

Navigation

* Easy-to-use navigation menu
* Internal links between all website pages

Forms

Contact Form

Allows users to:

* Submit general enquiries
* Send messages to the organisation

Enquiry Form

Allows users to:

* Enquire about adoptions
* Volunteer opportunities
* Sponsorship opportunities

JavaScript Features

* Client-side form validation
* Error messages displayed for invalid input
* Validation of:
    * Name fields
    * Email addresses
    * Phone numbers
    * Message length
* Dynamic search functionality
* Real-time filtering of services and content
* Form processing and response messages

Dynamic Content

* Search bar for filtering services
* JavaScript used to update content dynamically
* Improved user interaction and usability

SEO Features

* Meta descriptions
* Meta keywords
* Header tags (H1, H2, H3)
* Image alt text
* Internal linking
* Mobile optimisation
* robots.txt file
* sitemap.xml file
