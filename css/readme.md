PAWS & CLAWS ANIMAL RESCUE WEBSITE
=================================

Project Name:
Paws & Claws Animal Rescue

Description:
This is a responsive website created using HTML and CSS. The website promotes an animal rescue organization that helps abandoned and stray animals find safe and loving homes.

Files Included:
1. index.html
2. style.css
3. README.txt

CSS Features Used:
------------------
• External CSS Stylesheet
• CSS Selectors
• Background Colors
• Text Formatting
• Flexbox Layout
• Padding and Margins
• Box Shadow Effects
• Border Radius
• Hover Effects (optional)
• Responsive Design
• Media Queries

Responsive Design:
------------------
The website adapts to different screen sizes using CSS Media Queries.

Tablet View:
@media screen and (max-width: 768px)

Changes:
• Cards stack vertically
• Heading sizes adjust

Mobile View:
@media screen and (max-width: 480px)

Changes:
• Navigation menu becomes vertical
• Text becomes smaller
• Cards resize to fit mobile screens

Sections Included:
------------------
• Header
• Navigation Menu
• Hero Section
• Animal Rescue Information Cards
• Footer

Purpose:
--------
The purpose of this website is to provide information about animal rescue services and encourage animal adoption and volunteering.
